⚡ QuachArrow
QuachArrow — это лёгкая и быстрая утилита для Windows 10 и Windows 11, которая убирает и восстанавливает стрелки на ярлыках рабочего стола.

В отличие от стандартных твикеров, программа генерирует правильный прозрачный слой нужного размера и жестко сбрасывает системный кэш иконок, полностью исключая появление черных квадратов или белых листов на ярлыках.

✨ Особенности:
Без визуальных багов: Никаких черных квадратов на Windows 10/11.

Применение в 1 клик: Автоматическая чистка кэша и мгновенный перезапуск Проводника.

Портативность: Работает как один автономный .exe файл, не требует установки.

Красивый UI: Тёмная тема с неоновой подсветкой в стиле GreenPer Team.

Авто-права: Встроенный запрос прав Администратора для работы с реестром.

🚀 Как использовать:
Скачайте QuachArrow.exe (или ZIP-архив) из раздела Releases.

Запустите программу от имени Администратора.

Нажмите «Убрать стрелки» (или «Вернуть стрелки», если захотите всё вернуть).

Экран на секунду мигнёт (перезапустится explorer.exe), и изменения сразу применятся!
